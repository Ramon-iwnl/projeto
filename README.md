# BoardSurf — pré-projeto

Projeto em `boardsurf/`, preparado a partir do ZIP fornecido pelo aluno e das correções feitas nesta conversa.

- [Instalação e atualização no XAMPP](boardsurf/LEIA-ME-INSTALACAO.txt)
- [Comparação com os requisitos e validação](boardsurf/RELATORIO_PRE_PROJETO.md)
- [Roteiro de demonstração](boardsurf/TESTES_XAMPP.txt)
- [DER em imagem](boardsurf/DER-BoardSurf.png)

Copie a pasta `boardsurf` para `C:\xampp\htdocs\boardsurf`. Em instalação nova, importe `boardsurf/banco.sql`.
Em uma instalação existente, preserve o banco e suas configurações locais; não reimporte o catálogo para apenas atualizar o código.

Conta Master em banco novo: login `master`, senha `MasterAb`. Segundo fator: nome materno `Administrador`, nascimento `01/01/2000` ou CEP `20000-000`, conforme a pergunta sorteada.

Escopo: telas, validações, responsividade e DER do pré-projeto, com o PHP necessário para manter os fluxos funcionando.
